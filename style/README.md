# Style

My favourite colour theme and fonts, kept in one place so new tools can match them.

## Colour theme: Slate

Slate is my favourite colour theme: a cool, low-glare slate gray with muted accents and no pure white or black.

- Terminal: the colours in [ghostty/config](../ghostty/config).
- Zed: the "Slate" theme in [zed/themes/umber.json](../zed/themes/umber.json), generated by [zed/gen-theme.py](../zed/gen-theme.py) from the Ghostty colours.

## Fonts

Both are designed for low-vision readers. Copies live in [fonts/](../fonts).

- [Intel One Mono](https://www.intel.com/content/www/us/en/company-overview/one-monospace-font.html): code and terminal.
- [Atkinson Hyperlegible](https://www.brailleinstitute.org/freefont/): UI and reading text (the Next version).
